# Task 6: Host a Static Website with GitHub Pages

## Project Overview
A responsive static portfolio website built using HTML5 and CSS3 and deployed using GitHub Pages.

## Objectives
- Create a static website using HTML and CSS.
- Host the website using GitHub Pages.
- Learn GitHub repository management and web deployment.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## Features
- Responsive website layout
- About Me section
- Technical skills showcase
- Featured DevOps projects
- GitHub profile link

## Live Demo
**Website:** https://lalita-15.github.io/task-6-github-pages/

## GitHub Repository
**Source Code:** https://github.com/lalita-15/task-6-github-pages

## Deployment Steps
1. Created an `index.html` file with embedded CSS.
2. Pushed the source code to a GitHub repository.
3. Opened **Settings → Pages**.
4. Selected `main` branch and `/ (root)` folder.
5. Published and verified the live website.
